# XBot reference asset

xbot.glb is converted from the user's supplied Mixamo X Bot.fbx. It preserves 68
named scene nodes, two source meshes and skins with 65/64 joints, using up to four
normalized influences. The source contains no usable motion clips. Base colors are
neutral conversion values; textures/PBR extraction are not part of the ufbx helper.
The code-generated Demo clips belong to source/game/examples/models/proceduralClips.lua.
The engine source license does not replace the source asset's Mixamo/Adobe terms.
This high-poly asset is for functional demonstration, not a measured phone budget.
